# QA Portfolio

Портфолио проектов по ручному тестированию программного обеспечения (Manual QA).

В репозитории представлены учебные проекты, демонстрирующие навыки тестирования веб-приложений, составления тестовой документации, поиска и документирования дефектов, а также тестирования REST API.

## Проекты

### SauceDemo — Manual Testing

Тестирование интернет-магазина SauceDemo.

**Что было выполнено:**
- Составление чек-листов.
- Функциональное тестирование пользовательских сценариев.
- Поиск и документирование дефектов.
- Оформление баг-репортов.
- Работа с Jira, Git и GitHub.

[Перейти к проекту](./SauceDemo/README.md)

### Shady Meadows — UI & API Testing

Тестирование веб-приложения Shady Meadows B&B.

**Что было выполнено:**
- Функциональное тестирование пользовательского интерфейса.
- Проверка форм, навигации и бронирования номеров.
- Составление тест-кейсов.
- Тестирование REST API с использованием Postman.
- Проверка HTTP-статусов, ответов сервера и обработки некорректных запросов.
- Документирование обнаруженных дефектов.

[Перейти к проекту](./Shady-Meadows/README.md)

## Инструменты и технологии

- **Тестирование:** Manual QA, Functional Testing, UI Testing, API Testing.
- **API:** Postman, REST API, HTTP, JSON.
- **Документация:** Test Cases, Checklists, Bug Reports.
- **Управление задачами:** Jira.
- **Контроль версий:** Git, GitHub.

## О проекте

Все представленные проекты выполнены в учебных целях и предназначены для демонстрации практических навыков тестирования программного обеспечения.
