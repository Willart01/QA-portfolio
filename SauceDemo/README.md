# SauceDemo — Manual Testing

Учебный проект по ручному тестированию веб-приложения [SauceDemo](https://www.saucedemo.com/).

Цель проекта — получить практический опыт функционального тестирования веб-приложения, освоить составление тестовой документации, выявление и документирование дефектов.

## Объект тестирования

SauceDemo — демонстрационное веб-приложение интернет-магазина.

## Объём тестирования

В рамках проекта проверялись следующие функциональные области:

- Авторизация пользователя.
- Каталог товаров и сортировка.
- Добавление и удаление товаров в корзине.
- Оформление заказа.
- Проверка отображения данных заказа в PDF-файле.

## Тестовое окружение

- **ОС:** Windows 11 25H2.
- **Браузер:** Yandex Browser 26.8.0.0.
- **Тестовая среда:** SauceDemo.
