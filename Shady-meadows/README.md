# Shady Meadows — UI & API Testing

Учебный проект по ручному тестированию веб-приложения Shady Meadows B&B.

## Объект тестирования

Веб-приложение гостиницы, позволяющее пользователям просматривать номера, проверять доступность и оформлять бронирование.

**Сайт:** https://automationintesting.online/

## Область тестирования

### UI Testing
- Проверка навигации по страницам и разделам сайта.
- Проверка отображения информации о номерах.
- Тестирование формы поиска доступных номеров.
- Проверка полей ввода и валидации форм.
- Проверка сценариев бронирования.
- Проверка отображения информации и сообщений об ошибках.

### API Testing
- Проверка REST API.
- Проверка HTTP-статусов ответов.
- Проверка структуры и содержимого JSON-ответов.
- Тестирование авторизации и валидации токенов.
- Проверка обработки некорректных запросов.
- Проверка операций получения и изменения данных.

## Тестовая документация

В проекте представлены:

- `test-cases/shady-meadows-test-cases.xlsx` — тест-кейсы для UI-тестирования.
- `test-cases/Shady-meadows-API.xlsx` — тест-кейсы для API-тестирования.
- `bug-reports/` — скриншоты зарегистрированных дефектов.

## Инструменты

- Postman — отправка API-запросов и анализ ответов.
- Jira — регистрация и отслеживание дефектов.
- Excel — ведение тестовой документации.
- Git и GitHub — контроль версий и хранение проекта.

## Особенности проекта

Тестирование проводилось на публичной демонстрационной версии приложения. Тестовые данные могут сбрасываться, поэтому результаты отдельных проверок могут отличаться при повторном запуске.

Проект выполнен в учебных целях.
